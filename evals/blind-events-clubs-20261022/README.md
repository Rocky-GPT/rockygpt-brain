# Blind events and clubs check (written 2026-10-21/22)

Dan's 10-21 order: academics, then events and clubs, then production, then people. Written and
frozen BEFORE any events or clubs code was built: four writer agents from writer-brief.md alone, 15
questions each (first-year residents looking for things to do ec1; students joining clubs ec2;
sports fans and athletes ec3; commuters and upperclassmen after career, arts and academic events
ec4); exact repeats of any earlier eval question dropped. Questions with relative times ("tonight",
"this weekend") are judged against the calendar as of the run's own time. Run once on the finished
build, two graders per batch, worst of two. Pass bar: no answer wrong/serious by both graders;
correct + declined_ok + asked_ok at least 90%.
