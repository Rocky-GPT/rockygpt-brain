# AI Agent Instructions (Codex)

This repository is a clean-room implementation of RockyGPT Brain.

## Rules

- **NEVER create new git branches** (no `git checkout -b` or feature branches). Commit and push directly to `dev`.
- Do not read, inspect, copy, reference, or reuse old RockyGPT branches, commits, tags, tests, prompts, or architecture unless explicitly asked.
- Use only the current branch and instructions.
- Design from first principles.
- Keep things as simple as possible.
- Do not add abstractions or complexity before they are actually needed.
- Build one small step at a time.
- Do only what is asked, then stop.
